# PropostaFlow

API em .NET para gestão de propostas de crédito, com máquina de estados (Rascunho → EmAnalise → Aprovada/Reprovada). Projeto pessoal criado para estudo.

## Como rodar

```

dotnet run --project PropostaFlow.Api

```



## Como testar

```

dotnet test

```
